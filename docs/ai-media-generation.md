# AI 图像/视频生成使用指南

剪辑页集成了 AI 图像/视频生成功能，基于智谱 CogView-3-Flash（图像）和 CogVideoX-Flash（视频）。

## 功能位置

**左侧面板 → 媒体 tab → 「生成图片」「生成视频」按钮**（网格布局，在「导入素材」按钮上方）

## 使用流程

### 生成图片（5-10 秒）

1. 点击「生成图片」打开弹窗
2. 输入描述（如："一只猫坐在窗边看星空，赛博朋克风格"）
3. 点击「生成」按钮
4. 弹窗提示"生成任务已提交"，关闭弹窗
5. **素材列表自动刷新**，显示生成中的占位（spinner 遮罩）
6. 约 5-10 秒后，生成完成，占位变为可用图片
7. 拖入时间轴或点击添加

### 生成视频（1-3 分钟）

1. 点击「生成视频」打开弹窗
2. 输入描述（如："海浪拍打沙滩，夕阳西下"）
3. 点击「生成」按钮
4. 弹窗提示"生成任务已提交（约 1-3 分钟）"
5. **素材列表自动显示生成中状态**，每 3 秒自动刷新进度
6. 约 1-3 分钟后，生成完成，可拖入时间轴

## 技术细节

- **生成中状态**：Asset 显示 spinner 遮罩 + "生成中…"，不可拖拽/添加
- **生成失败**：Asset 显示红色遮罩 + "生成失败"，可点删除按钮清理
- **自动轮询**：前端检测到 `status=generating` 的 Asset 时，每 3 秒自动刷新素材列表
- **存储方式**：生成完成后下载到服务端 `storage/uploads/`，与手动上传的素材走相同流程

## 模型规格

| 类型 | 模型               | 尺寸/时长            | 生成耗时 |
| ---- | ------------------ | -------------------- | -------- |
| 图片 | CogView-3-Flash    | 1024x1024（固定）    | 5-10 秒  |
| 视频 | CogVideoX-Flash    | 720p、6 秒（固定）   | 1-3 分钟 |

## Prompt 建议

### 图片

- **风格示例**："赛博朋克风格"、"水彩画风"、"写实摄影"
- **细节描述**："一只橘猫坐在窗边，背景是星空和城市夜景"
- **避免**：过长的文本（< 100 字），过于抽象的概念

### 视频

- **动作描述**："海浪拍打沙滩"、"日出时的云层变化"、"汽车驶过雨中街道"
- **场景要素**："夕阳西下，海鸥飞过"
- **避免**：复杂剧情、多主体动作（模型生成能力有限）

## 本地开发测试

1. **环境变量**：确保 `apps/api/.env` 填入真实的智谱 API Key
   ```bash
   GLM_API_KEY=your-actual-api-key-from-bigmodel.cn
   GLM_IMAGE_MODEL=cogview-3-flash
   GLM_VIDEO_MODEL=cogvideox-flash
   ```

2. **启动服务**：
   ```bash
   cd apps/api && pnpm dev    # 后端 http://localhost:3888
   cd apps/web && pnpm dev    # 前端 http://localhost:5173
   ```

3. **测试路径**：
   - 进入任意项目编辑页
   - 左侧面板切到「媒体」tab
   - 点击「生成图片」，输入 prompt 提交
   - 观察素材列表：应立即出现 generating 占位，5-10 秒后变为可用图片
   - 点击「生成视频」测试视频生成（1-3 分钟）

## 常见问题

**Q：生成失败显示红色遮罩怎么办？**  
A：鼠标悬停在失败的素材上，点右上角删除按钮清理。失败可能是 API Key 无效、智谱服务异常或 prompt 违规。

**Q：生成视频后看不到内容？**  
A：视频需要 1-3 分钟，素材列表会自动刷新。如果超过 5 分钟还是 generating，可能是智谱服务慢或超时，刷新页面重试。

**Q：能否控制视频时长或图片尺寸？**  
A：当前 MVP 版本固定（图片 1024x1024，视频 6s、720p），后续可扩展支持更多参数。

## 技术实现

- 后端：`POST /api/ai-gen-media/image` / `POST /api/ai-gen-media/video` → BullMQ 异步任务
- LLM 抽象层：`@reel/ai-gen` 包 (`ZhipuAiGenProvider`)
- 前端组件：`AiMediaGenDialog.tsx` + `LeftPanel.tsx` 集成
- 轮询逻辑：`useAssets()` 检测 `generating` 状态，自动 3 秒刷新
